## Задачи (.tasks/)

В проекте ведётся трекер задач в `.tasks/` (формат — `.tasks/README.md`), работать с ним через скилл `task-tracker`.
- Нетривиальная работа (правка кода больше пары строк, исследование, фича, баг) привязывается к задаче: найди подходящую (`list`, `next`) или заведи, переведи в `in_progress` до начала правок, по ходу пиши `note`, в конце — `Result`, отметь критерии и переведи в `review` через гейты. Мелкие вопросы и разовые ответы задач не требуют.
- Задача в `in_progress` у другой сессии — не трогай её, бери другую.
- `icebox` — отложенные задачи: сам их не бери и не предлагай. Вывести из icebox (в `backlog`) можно только когда пользователь явно попросил про эту задачу (по номеру или описанию): `move … --by user --note "<его слова>"`.
- Файлы в `.tasks/` руками не правь — только через `tasks.mjs`, иначе теряется история.
- В `done` переводит пользователь (или ты — по его явному «принимаю/закрывай»).
